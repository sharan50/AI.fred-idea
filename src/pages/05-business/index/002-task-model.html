2The task model

Every task resolves into one of five outcomes, and the mix is what sets the cost base.

Table 5.1 Every task resolves to one of five outcomes; the mix sets the cost base. assumption
TierWhat it isShare, working assumption
AI-onlyThe agent reached the acceptance artefact with no human action45 per cent
AssistedThe agent did the bulk; a person executed bounded steps50 per cent
Human-ledA person owned the task; the AI supported5 per cent
BouncedCompletion required an act only the user can performrecorded separately
FailedNo acceptance artefact, and not because of a bouncerecorded separately

Bounced is deliberately not folded into human-led. It costs almost no labour and therefore barely moves headcount, but it is the outcome that spends the product promise, because the user is handed the task back. It is a product metric, not a cost metric.
