6The invariant

Nowhere is a person more tempted to leave a task for later than at the console, so the rule that forbids it is stated here in exactly the words used in the state machine in 02. The harness checks that the two are character for character the same.

A task never leaves the system by omission. Every task is in exactly one named state. Every non-terminal state carries a live timer. Every change of state is an explicit, recorded transition, and no task reaches a terminal state without one. Silence from the user is a legitimate way for a task to end: it moves through visible nudges into lapsed, and lapsed is not withdrawn. Silence from the system is forbidden: a task with no live timer is an exception, and the watchdog places it on the exceptions board until a person gives it one.

For a worker the invariant has three practical consequences. A card never closes without a code, so nothing a worker touches can end by being put down. A check never times out into an act, so nothing irreversible fires because someone was slow. And the board is a duty with an owner, so a task that has fallen silent is somebody's job by name until it is not silent. The decision behind the machine is DR-005.
