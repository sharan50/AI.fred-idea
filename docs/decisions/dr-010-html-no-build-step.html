DR-010Plain HTML with no build step

The publication is plain static HTML under the docs directory, served by Netlify straight from GitHub with no build command, no framework, no CDN and no external asset. HTML is the single canonical source. A static site generator and Markdown-canonical generation were both rejected, because two representations of one document drift.

On this page

1Decision

The docs directory is plain static HTML and nothing else is served. Netlify publishes it straight from GitHub; the publish directory is pinned in netlify.toml and there is no build command. HTML is the single canonical source of every page, written as semantic HTML so the site stays machine-readable. Vanilla JavaScript is used for navigation only, in one file. Diagrams are inline SVG. Every page exports cleanly to PDF through a print stylesheet. A manifest.json maps the site for humans and machines. The repository is the venture's vault: design documents now, application code later in the same repository, professional setup after the raise.

1.1Why there is no build step

A build step is a second thing that has to be correct. With none, the file in the repository is the file the reader receives; a reviewer reads exactly what an investor will open; and the verification harness checks the served artefact itself rather than an input to a generator. The only tool in the publishing path is tools/verify.mjs, which reads and never writes. A page that passes it is published by a commit, and nothing between the commit and the URL can change it.

1.2Why HTML is canonical

The alternatives put the truth in one representation and the reader in another. What the pages need is not expressible in a lighter source: status chips at clause end, numbered sources with addressed links, figure blocks with a focusable scroll region and a numbered caption, tables with captions and a header row, a stamp that carries a data attribute the harness reads. Each of those would be either raw HTML embedded in Markdown, at which point the Markdown is no longer the simpler form, or a generator extension, at which point the build step has returned by another door. Writing the HTML directly costs an authoring discipline: every page copies one template, numbers its headings in the text, and a change to the masthead is a find-and-replace across the pages. The harness catches every slip, and the page count is small enough that the discipline is cheaper than the machinery.

1.3Access

A Netlify URL is public by default. Access control is an amber item in 07, as 07 records it, with the interim mitigation of an unguessable site name, a no-index directive on every page and a no-index header; the interim mitigation is not access control, and 07 says so. One further observation is recorded there: the manifest sits at the repository root, outside the published directory, so a machine fetching the site cannot read it until it is copied in.

2Rejected alternative(s) and their cost

A static site generator
A build step and a dependency tree in the publishing path, templates in a second language, and a generated output nobody reviews because everyone edits the input. The harness would check the input, not what is served, and the generator's own upgrades would change pages nobody touched. The cost of rejecting it is the authoring discipline above.
Markdown as the canonical source, with HTML generated from it
Two representations of one document, and they drift: the Markdown lacks the markup the design needs, so the generated HTML acquires hand edits, and within a month the file people read is not the file people edit. Rejected because a design record with two versions is a design record with none.
A framework or a hosted documentation platform
A runtime the print stylesheet fights, scripts beyond navigation, external asset loads on every page view, and a URL that cannot stand alone offline or in front of an investor without a vendor's chrome around it. The visual reasons are recorded in DR-011.
Fonts or stylesheets from a CDN
A third party sees every reader of a document that is not yet meant to circulate; the page fails when the CDN does; and the brief forbids the load. The fonts are self-hosted under their open licence instead.

3What this closes off

  • A build command in netlify.toml, a package manifest in the publishing path, or any generated file under the docs directory, with one exception recorded on 2026-09-10: the dependency map's served view at docs/depmap/, generated by the map's own tool from graph.json, committed, and failed by the harness when it is stale (DR-017).
  • Any script other than nav.js, and any network, storage, cookie or dynamic-import call inside it; the harness scans for each by name. The map's served view carries its own script and stylesheet and sits outside the page floor by that one exception; the harness holds it instead to freshness, the no-index directive and no external load.
  • An external asset load of any kind: font, stylesheet, script or image from any host. External links are allowed in prose only, on an anchor.
  • A Markdown or other second copy of any page, and any page absent from manifest.json.
  • Raster images, embedded frames and media elements; a diagram is inline SVG or it is prose.
  • Circulating a URL before the access item in 07 is resolved.

4Status

Fixed decision, taken by the founder and recorded in the brief's ledger on 2026-09-02. Connecting the repository to Netlify and resolving the access item are the founder's steps after the build loop surfaces; the visual system that sits on this decision is DR-011 and the plan built from it is DR-012. Revised 2026-09-10 by the founder: one generated page, the dependency map's served view, is admitted under docs/depmap/ as DR-017 records, so the map can be followed from the published workspace; every other line of the closure stands, and the exception is named in the closure above rather than left to the harness to imply.

AI.fred is a personal AI that builds your context, task by task, to do in your personal life what the general assistants do, and that can be trusted with the high-value, low-volume tasks you dread a few times a year: the ones that carry real consequence.
